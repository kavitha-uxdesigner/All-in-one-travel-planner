
# All-in-One Travel Planning App ✈️

## Project Overview
An AI-powered travel planning and booking app designed to help users organize their trips in one place.

## Problem Statement
Planning a trip can involve multiple apps for flights, hotels, itineraries, and accessibility needs.

## Key Features
- Flight and hotel search and booking
- Personalized itinerary planning
- AI-powered travel recommendations
- Wheelchair assistance and accessible travel planning
- Trip summary and booking management

## Design Goals
- Simplify the travel planning process
- Make essential travel information easy to find
- Create a user-friendly and accessible experience

## Tools Used
- Figma
- Wireframing
- Prototyping
- UI/UX Design
